# 0001: Toolchain and version pins

- **Status:** Accepted (2026-11-18)
- **Story:** E0.S1 AC4

## Context

Several key dependencies are new or pre-release: SolidJS 2.0.0 shipped on 2026-11-17, `tauri-specta` and `specta` 2.x are release candidates, and Tauri 3 is in alpha. Unpinned ranges would let any of them change under us.

## Decision

Pin exact versions (no `^` or `~`) and commit every lockfile (`Cargo.lock`, `apps/desktop/pnpm-lock.yaml`, `apps/mobile/pubspec.lock`). Upgrades happen through Dependabot PRs, which CI must pass.

Notes:

- `vite-plugin-solid` has moved to `@solidjs/vite-plugin`, which reached 3.0.1 (stable, Solid 2 only) on 2026-11-17. The plan's earlier note that 2.0 support was prerelease-only is out of date.
- pnpm's `minimumReleaseAge` setting held back the newest Solid packages. `apps/desktop/pnpm-workspace.yaml` lists the exact versions excluded from that gate. Remove entries once they're older than the gate.
- tauri-specta uses `ErrorHandlingMode::Result`, so a command returning `Result<T, AppError>` becomes `{ status: "ok", data } | { status: "error", error }` in TypeScript (plan §3.5, E7.S1 AC3).
- Typed error unions only come from commands that return `Result`. Framework-level failures (unknown command, ACL denial) still reject the promise.

- **Mobile Rust builds use `stable`, not the pin.** cargokit only accepts `stable`, `beta` or `nightly`, and runs `rustup run stable cargo build`. Today stable is 1.98.0, the same as the pin. If they drift, mobile and desktop builds use different compilers; CI installs `stable` for the mobile jobs.
- **The FFI package is named `mt_ffi` (underscore).** cargokit looks for `lib<package-name>.so`. With a hyphenated name it silently copied nothing into the APK and the app would crash at `RustLib.init()`.
- Mobile bridge glue (`apps/mobile/rust_builder`) was generated by `flutter_rust_bridge_codegen integrate` (cargokit backend) and then pointed at `crates/mt-ffi`. Only the Android and iOS platforms are kept.

## Consequences

- Upgrades are deliberate and reviewable, at the cost of more Dependabot PRs.
- A tauri-specta or specta RC bump may change generated `bindings.ts`. CI fails if the committed file is stale.
