# Architecture decision records

One file per decision: `NNNN-short-title.md`, numbered in order. Each has:

- **Status**: Proposed, Accepted, or Superseded by NNNN
- **Context**: what forced the decision
- **Decision**: what we chose
- **Consequences**: what follows, good and bad

Write one for every spike result, every deviation from [`plan.md`](../../plan.md), and every owner decision on an open question (plan §7).
